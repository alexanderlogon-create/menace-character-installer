MENACE Character Installer 0.3.2 - complete source for review

Requires Windows x64 and the Microsoft .NET 10 SDK. NuGet dependencies are restored from their public package feeds during compilation.

Extract the source ZIP and run from its root:

dotnet publish installer/MenaceCharacterInstaller.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish

The resulting publish/MenaceCharacterInstaller.exe includes the Waybackers catalog and resources. Source contains the same catalog.json and payload archives used by the uploaded 0.3.2 EXE, including the required All Leaders Pickable declaration. The bundled data are the pack author's published Waybackers content, split by stable character IDs; original voice and gameplay operations are preserved.

Application source: installer/MenaceCharacterInstaller.App
File selection, dependency setup, downloading, import and rollback: installer/MenaceCharacterInstaller.Core
Bundled data, pinned download manifest and library notices: installer/content

The single-file host extracts native runtime components and the application extracts its checksum-verified character payload to the user's LocalApplicationData folder. This packaging may require review under Nexus' executable/self-extracting-file policies. No claim is made about the specific cause of the current quarantine.

The source snapshot excludes developer build caches, private Studio projects, save files, logs, credentials and the local SDK installation. Asset previews and catalog names are public mod content. See README.md for release identification and the review map.
